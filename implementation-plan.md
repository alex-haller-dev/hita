## Implementation plan
The purpose of this document is to describe how to implement the unfinished pages.

## General instructions
I have left a bunch of TODOs in the code base for the unfinished pages. Your job is to go over all the TODOs
and implement them.

## CRM support
Some pages like projects and news need CRM support. Do not implement these pages. We don't have access
to the CRM yet and we don't want to add a bunch of mock data since we don't know the structure of the data
in the existing CRM.

## Consistency
Make sure that when you design the pages, that you keep a consistent style and feel to the pages, the website
needs to be coherent as a whole.

## Content
Please make sure that in terms of information you cover the same information that is present on the original
website (hita-ev.org). If you think some content is redundant, you can leave it out but please make note of what
you left out. Further, you are allowed to reword the content.

## What if you are unsure?
Do not ask me questions during implementation. You can take your time, even do research, the task can run as long
as you want, but make sure it runs in one go without any interruptions. Always just use your best judgment.

If you implement something you weren't sure about, take note, and report that to me by the end so I know
where to look carefully.

I will review each change individually afterwards.

## Consistency across languages
We have one page per language and type of page, but you need to make sure that when you implement the pages
that across the languages the conent of the pages themselves should be the same. Meaning, if you look at
the "support" page in german, you should see the same content as if you would look at the english page.

The website itself needs to be different language pages only exist to translate the content, not substantially
alter the content of the page.
